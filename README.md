# 🤟 GestureSync AI — World-Class Neural Sign Language to Text & Multimodal Speech Translator

> **The Next-Generation Real-Time Neural Sign Language Translation & Two-Way Multimodal Conversation Platform.**  
> Powered by Computer Vision Landmark Kinematics, Web Speech Synthesis, and Accessibility-First Interface Design.

---

## 🌟 Overview & Key Highlights

**GestureSync AI** bridges the communication divide between Deaf/Hard-of-Hearing individuals and vocal hearing communities worldwide. Engineered with cutting-edge UI/UX, low-latency edge kinematic tracking, multi-language speech synthesis, and gamified sign academies, this platform sets a new benchmark in accessibility technology.

### 🚀 Core Innovations & Features

1. **🎥 Real-Time Sign Translation Studio (Camera / Neural Kinematics)**
   - **Live WebCam Feed**: Direct video feed with dynamic camera flip & privacy controls.
   - **21-Point Hand Landmark Mesh**: Real-time rendering of all 21 hand joints (Wrist, Thumb, Index, Middle, Ring, Pinky) with glowing cyberpunk cyan & emerald telemetry connections.
   - **Real-Time Telemetry HUD**: Live 60 FPS counter, sub-15ms edge latency tracker, and spatial confidence indicators.
   - **Interactive Gesture Sandbox**: Quick-selection test strip for immediate verification of alphabets, numbers, and common life phrases.

2. **🔊 Multimodal Text & Speech Translation Engine**
   - **Multi-Dialect Grammar Smoothing**: Converts raw ASL/ISL grammar gloss (e.g. `HELLO MEET YOU NICE`) into natural, fluent English, Hindi (`नमस्ते, आपसे मिलकर बहुत खुशी हुई!`), or Spanish.
   - **Natural Voice Synthesis**: Native integration with the browser's Web Speech API (`SpeechSynthesis`), featuring customizable speech rate (0.8x - 1.5x), pitch, and neural voice selector.
   - **Reactive Audio Waveform Visualizer**: Real-time frequency bars animated in sync with vocal speech playback.
   - **One-Click Transcripts**: Export timestamped transcripts directly to text files or copy to clipboard.

3. **🎙️ Voice-to-Sign Reverse Communication Studio (Two-Way Bridge)**
   - Enables hearing individuals to speak or type messages that are automatically translated into animated sign language sequences and finger-spelling illustrations for Deaf listeners.
   - Step-by-step sequential playback with timeline scrubber, pause/play, and speed adjustments.

4. **🔐 Ultra-Modern Authentication System (Sign In & Sign Up)**
   - Glassmorphic modal interface with instant **1-Click Demo Guest Login**.
   - Sign Up featuring **Dynamic Password Strength Bar** (Weak, Medium, Strong, Military-Grade).
   - Tailored role selection: *Deaf / Hard-of-Hearing*, *Certified Interpreter*, *Student / Learner*, or *Healthcare Worker*.
   - "Remember Me" session persistence and forgot password recovery flow.

5. **🆘 Critical Emergency SOS Broadcast HUD**
   - Immediate 1-touch triggers for **Ambulance / Medical**, **Police**, **Fire**, and **Lost Distress**.
   - High-contrast visual beacon card for paramedics and first responders.
   - Audio synthesizer alarm siren and emergency voice loop.
   - Simulated GPS geo-coordinates beacon.

6. **🎓 Interactive Sign Academy & Gamified Quiz**
   - Searchable sign library categorized by *Greetings*, *Courtesy*, *Responses*, *Emergency*, *Daily Life*, and *Alphabets*.
   - Interactive 4-choice practice quiz with **confetti celebration explosions** on correct recognitions!

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Obsidian Glassmorphic Design System
- **Icons**: Lucide Icons
- **Visuals & Animations**: HTML5 2D/3D Kinematic Canvas + `canvas-confetti`
- **Audio Synthesizer**: Web Audio API (tactile clicks, success chimes, SOS sirens)
- **Speech Engine**: Web Speech API (`speechSynthesis` + `webkitSpeechRecognition`)

## 💻 Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/Anamika-2006/SignLangTran.git
cd SignLangTran

# 2. Install dependencies
npm install

# 3. Launch development server
npm run dev

# 4. Build for production
npm run build
```
